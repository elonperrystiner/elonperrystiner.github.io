# Elon Perry-Stiner — Portfolio

A static portfolio built with HTML, CSS, and JavaScript. All fonts and project media are served locally.

## Preview

Run `python3 -m http.server 4173` from this directory, then open http://localhost:4173.

## GitHub Pages

In repository Settings → Pages, select “Deploy from a branch,” then the main branch and / (root). No build step is required. A custom domain can be connected after the Pages deployment is working.

The portfolio includes selected professional and collaborative work. Project media retain their respective owners’ rights. Font licenses are included in assets/fonts.
